# 🚀 Система прав доступа для Django проекта

## 📋 Описание

Данный проект реализует полноценную систему прав доступа для управления продуктами с ролями владельца и модератора.

## ✨ Реализованные функции

### 🔐 Группа "Модератор продуктов"
- **Создана группа** с правами на управление продуктами
- **Права группы:**
  - `can_unpublish_product` - отмена публикации продукта
  - `delete_product` - удаление любого продукта
  - `change_product` - изменение любого продукта
  - `view_product` - просмотр продуктов

### 👤 Владельцы продуктов
- **Автоматическое назначение** владельца при создании продукта
- **Проверка прав** для редактирования и удаления только владельцем
- **Безопасность** - модераторы не могут редактировать чужие продукты

### 🛡️ Проверки безопасности
- **На уровне представлений** - проверка прав перед выполнением действий
- **На уровне шаблонов** - скрытие/отображение элементов по правам
- **Автоматическая привязка** владельца к продукту

## 🚀 Установка и настройка

### 1. Применение миграций
```bash
python manage.py makemigrations
python manage.py migrate
```

### 2. Создание групп и прав
```bash
python manage.py create_groups
```

### 3. Создание суперпользователя
```bash
python manage.py createsuperuser
```

## 🔧 Использование

### Для модераторов:
1. **Войти в админку** Django
2. **Добавить пользователя в группу** "Модератор продуктов"
3. **Использовать права** на отмену публикации и удаление

### Для владельцев:
1. **Создать продукт** - автоматически становится владельцем
2. **Редактировать/удалять** только свои продукты
3. **Управлять статусом** публикации

## 🧪 Тестирование

### Проверка прав модератора:
1. Создать пользователя
2. Добавить в группу "Модератор продуктов"
3. Проверить возможность отмены публикации

### Проверка прав владельца:
1. Войти под пользователем
2. Создать продукт
3. Проверить возможность редактирования

## 📝 API endpoints

- `POST /products/<id>/unpublish/` - отмена публикации (требует права `can_unpublish_product`)
- `GET /products/<id>/` - просмотр продукта
- `POST /products/create/` - создание продукта (автоматически назначает владельца)
- `PUT /products/<id>/update/` - редактирование (только владелец)
- `DELETE /products/<id>/delete/` - удаление (владелец или модератор)
